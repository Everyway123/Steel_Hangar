# Регресія

```bash
npm i playwright            # один раз
node tests/regression.js    # усе
node tests/regression.js stuck ally hangar   # окремі блоки
```

Хромів бінарник береться з `/opt/pw-browsers/chromium`; свій шлях можна
передати через `CHROMIUM_PATH`.

Кожен блок стереже помилку, яка колись була справжньою:

| блок | що ловить |
|---|---|
| `stuck` | танк, замурований у стіні, і кулі, що гаснуть об власну стіну |
| `spawn` | ворог, народжений усередині сталевої фортеці штабу |
| `boss` | корпус боса, ширший за прохід між стінами |
| `star` | ★, яка не підсилює танк |
| `ally` | союзник, що кидає гравця, не бере трофеї й тре об стіну |
| `freexp` | досвід, що зникає в кінці гілки досліджень |
| `hangar` | ангар, який не влазить в один екран |
| `maps` | карта, на якій танк не може зрушити зі старту |

Тести читають `index.html` напряму з `file://` — збирати нічого не треба.
Гра навмисно тримає ігровий стан у глобальних змінних, тож перевірки
викликають ігрові функції (`startBattle`, `moveTank`, `takeStar`) як є.
